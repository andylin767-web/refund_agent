# Contributing

Thank you for helping improve Refund Agent.

1. Create a focused branch from the default branch.
2. Create and install the development environment with `make setup`.
3. Add or update tests with every behavior change.
4. Run `make check` before opening a pull request.
5. Explain security, configuration, or compatibility effects in the pull request.

Keep changes small and avoid real customer, order, payment, or credential data in
tests and examples. Report suspected vulnerabilities privately as described in
`SECURITY.md` rather than opening a public issue.
