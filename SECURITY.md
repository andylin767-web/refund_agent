# Security policy

## Supported versions

Refund Agent is pre-alpha and does not yet have a supported production release.
Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository.
Do not include credentials, payment data, personal data, or exploit details in a
public issue. Include affected versions, impact, reproduction steps, and any
suggested mitigation.

If a credential may have been exposed, revoke or rotate it immediately. Removing
it from a commit is not sufficient because it may remain in Git history.
